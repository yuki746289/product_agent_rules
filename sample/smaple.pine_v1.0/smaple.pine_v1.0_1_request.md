# smaple.pine v1.0 要件定義書

## 1. 目的・背景

[ADD] TradingView のチャート上に EMA を3本表示する Pine Script を作成します。

[ADD] 複数期間の EMA を同時に表示することで、短期・中期・長期のトレンドを視覚的に確認できるようにします。

## 2. 対象範囲

[ADD] 対象ファイルは `smaple.pine` とします。

[ADD] Pine Script として、チャート上に3本の EMA ラインを表示する処理を対象とします。

[ADD] EMA の期間、色、線幅をユーザーが設定できる入力項目を対象とします。

## 3. 対象外

[ADD] 売買シグナル、アラート条件、バックテスト用 strategy 処理は対象外とします。

[ADD] EMA 以外の移動平均線、マルチタイムフレーム取得、外部データ取得は対象外とします。

## 4. 入力要件

| 種別 | 内容 | 初期値 |
|---|---|---|
| [ADD] 価格ソース | EMA 計算に使用する価格 | close |
| [ADD] EMA1期間 | 1本目の EMA 期間 | 20 |
| [ADD] EMA2期間 | 2本目の EMA 期間 | 50 |
| [ADD] EMA3期間 | 3本目の EMA 期間 | 200 |
| [ADD] EMA1色 | 1本目の表示色 | 任意 |
| [ADD] EMA2色 | 2本目の表示色 | 任意 |
| [ADD] EMA3色 | 3本目の表示色 | 任意 |
| [ADD] 線幅 | EMA ラインの太さ | 2 |

## 5. 出力要件

| 種別 | 内容 |
|---|---|
| [ADD] チャート表示 | EMA を3本、価格チャート上に重ねて表示します。 |
| [ADD] ログ | Pine Script の仕様上、実行ログ出力は対象外とします。 |
| [ADD] エラー出力 | コンパイルエラーが発生しないコードを作成します。 |

## 6. 実行要件

[ADD] TradingView の Pine Script エディタでコンパイルできることを前提とします。

[ADD] インジケーターとしてチャートへ追加したとき、価格チャート上に EMA が3本表示されることを完了条件とします。

[ADD] 再実行時も同じ入力値に対して同じ EMA が表示されることを前提とします。

## 7. 制約条件

[ADD] Pine Script を使用します。

[ADD] コード工程では `.rules_v6/dev/rules_dev_other.md` の Pine 追加ルールを参照します。

[ADD] ファイル名はユーザー指定どおり `smaple.pine` とします。

[ADD] 開発手順は v6 の batch ルールに沿って進めます。

## 8. 受入条件

- [ ] [ADD] Pine Script エディタでコンパイルエラーが発生しないこと。
- [ ] [ADD] チャート上に EMA が3本表示されること。
- [ ] [ADD] EMA の期間をユーザーが変更できること。
- [ ] [ADD] EMA の色をユーザーが変更できること。
- [ ] [ADD] EMA の線幅をユーザーが変更できること。
- [ ] [ADD] 売買シグナルやアラートなど、対象外機能が含まれていないこと。

## 9. 未決事項

[ADD] EMA の初期色は基本設計工程で決定します。

[ADD] Pine Script のバージョンは基本設計工程で決定します。
