# batch SQLコード実装規約確認

## 1. 使用方法

- SQLを作成、変更またはレビューする前に、本ファイルを対象案件の成果物フォルダへコピーして使用して下さい。
- 各項目へ`対象 / 対象外 / 未確認`、`OK / NG / N/A`および確認根拠を記録して下さい。
- 対象外には理由を記録し、未確認またはNGが1件でもある場合は手順8・9・10を合格にしてはいけません。
- 再修正した場合は、再修正差分と影響範囲について確認をやり直して下さい。

## 5. 目視確認

- [ ] 通常のクエリを `library.libDatabase` 経由で実行している。
- [ ] 主テーブルが `tm`、JOINが `ts_1` 以降、サブクエリが `tt_1` 以降である。
- [ ] `SELECT *` を使わず、全カラムに `AS` とテーブル略称付きの列別名がある。
- [ ] SQL文字列が `String sql = " "` から始まり、`+` の位置が揃っている。
- [ ] 列別名を変えた場合、Java、Servlet、JavaScriptおよびMapのキーも合わせている。
- [ ] 変更した全ての関数またはメソッドを、先頭から末尾まで確認した。
- [ ] 変更と無関係な既存コードを一括修正していない。
