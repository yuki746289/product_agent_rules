# 仕様_全体_v1.0

## 1. 概要

`smaple.pine` は、TradingView の価格チャート上に EMA を3本表示する Pine Script インジケーターです。

## 2. 目的

短期・中期・長期の EMA を同一チャート上に表示し、トレンドの方向や価格との位置関係を視覚的に確認できるようにします。

## 3. 対象範囲

| 項目 | 内容 |
|---|---|
| 対象ファイル | `smaple.pine` |
| 実装ファイル | `sample/smaple.pine_v1.0/smaple.pine_v1.0.pine` |
| 実行環境 | TradingView Pine Script v6 |
| 表示対象 | EMA 3本 |

## 4. 機能仕様

| 機能 | 内容 |
|---|---|
| インジケーター表示 | `overlay=true` により価格チャート上へ表示します。 |
| EMA1表示 | 初期期間20の EMA を表示します。 |
| EMA2表示 | 初期期間50の EMA を表示します。 |
| EMA3表示 | 初期期間200の EMA を表示します。 |
| 入力変更 | 価格ソース、期間、色、線幅をユーザーが変更できます。 |

## 5. 入力仕様

| 入力 | 型 | 初期値 | 説明 |
|---|---|---|---|
| Source | series float | close | EMA 計算に使用する価格ソース |
| EMA 1 Length | int | 20 | EMA1 の期間 |
| EMA 2 Length | int | 50 | EMA2 の期間 |
| EMA 3 Length | int | 200 | EMA3 の期間 |
| EMA 1 Color | color | color.teal | EMA1 の色 |
| EMA 2 Color | color | color.orange | EMA2 の色 |
| EMA 3 Color | color | color.purple | EMA3 の色 |
| Line Width | int | 2 | EMA ラインの太さ |

## 6. 出力仕様

| 出力 | 内容 |
|---|---|
| EMA 1 | EMA1 のラインをチャートへ表示します。 |
| EMA 2 | EMA2 のラインをチャートへ表示します。 |
| EMA 3 | EMA3 のラインをチャートへ表示します。 |

## 7. 対象外

売買シグナル、アラート条件、バックテスト用 strategy 処理、マルチタイムフレーム取得、外部データ取得は対象外です。

## 8. エラー処理・制約

期間と線幅は `minval=1` とし、0以下の値を入力できないようにします。

TradingView Pine Script エディタでの実コンパイルはローカル環境では未実施です。

## 9. 運用・確認方法

TradingView の Pine Script エディタにコードを貼り付け、コンパイル後にチャートへ追加して EMA が3本表示されることを確認します。

## 10. 既知の注意点

`pine/.rules/pine_checklist.md` はローカルに存在しなかったため、Pine 追加ルールのチェックリスト参照とログ記録は保留です。
