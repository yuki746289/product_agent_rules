# app CSSコード実装規約確認

## 1. 使用方法

- CSSを作成、変更またはレビューする前に、本ファイルを対象案件の成果物フォルダへコピーして使用して下さい。
- 各項目へ`対象 / 対象外 / 未確認`、`OK / NG / N/A`および確認根拠を記録して下さい。
- 対象外には理由を記録し、未確認またはNGが1件でもある場合は手順8・9・10を合格にしてはいけません。
- 再修正した場合は、再修正差分と影響範囲について確認をやり直して下さい。

## 5. 目視確認

- [ ] 共通CSSと画面別CSSの配置先が責務と一致している。
- [ ] 新規セレクタは直接子の `>` を優先している。
- [ ] 固定幅の横超過を、先に `max-width`、`min()`、`max()`、`clamp()`、flex/gridで検討している。
- [ ] メディアクエリを追加した場合、段階的な切替が必要な理由を記録している。
- [ ] 確認幅 `320px`、`375px`、`414px`、`799px`、`800px`、`801px`、`1024px`、`1366px` を対象にしている。
- [ ] 変更した全ての関数またはメソッドを、先頭から末尾まで確認した。
- [ ] 変更と無関係な既存コードを一括修正していない。
