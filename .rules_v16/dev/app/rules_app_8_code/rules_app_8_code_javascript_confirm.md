# app JavaScriptコード実装規約確認

## 1. 使用方法

- JavaScriptを作成、変更またはレビューする前に、本ファイルを対象案件の成果物フォルダへコピーして使用して下さい。
- 各項目へ`対象 / 対象外 / 未確認`、`OK / NG / N/A`および確認根拠を記録して下さい。
- 対象外には理由を記録し、未確認またはNGが1件でもある場合は手順8・9・10を合格にしてはいけません。
- 再修正した場合は、再修正差分と影響範囲について確認をやり直して下さい。

## 5. 目視確認

- [ ] `importJs` 完了後に `init()`、`setEvent()` の順で呼んでいる。
- [ ] DOM取得とイベント登録が `id` と一致している。
- [ ] サーバ通信の関数名が `ClassServerMethod`、`ClassServer`、API、Servletで揃っている。
- [ ] 画面URLを `ClassCommon.js` の `selectUrl` / `link` / `typePage` で管理している。
- [ ] 連続する代入、Object、引数の位置を揃えている。
- [ ] 変更した全ての関数またはメソッドを、先頭から末尾まで確認した。
- [ ] 変更と無関係な既存コードを一括修正していない。
