# batch HTMLコード実装規約確認

## 1. 使用方法

- HTMLを作成、変更またはレビューする前に、本ファイルを対象案件の成果物フォルダへコピーして使用して下さい。
- 各項目へ`対象 / 対象外 / 未確認`、`OK / NG / N/A`および確認根拠を記録して下さい。
- 対象外には理由を記録し、未確認またはNGが1件でもある場合は手順8・9・10を合格にしてはいけません。
- 再修正した場合は、再修正差分と影響範囲について確認をやり直して下さい。

## 5. 目視確認

- [ ] headの順序、viewport、CSS、JavaScriptおよび埋め込みCSSが規約どおりである。
- [ ] `idLayout`、`idLayoutHeader`、`idLayoutContents`、`idLayoutFotter` と `clsCommonLayout_4` を維持している。
- [ ] idは `id`、classは `cls` で、JSの取得キーにclassを使っていない。
- [ ] 画面固有DOMのコメントと、意味のある開始タグ直前の短いコメントがある。
- [ ] HTML文字列の組み立てで、変換結果を先に変数へ格納している。
- [ ] 変更した全ての関数またはメソッドを、先頭から末尾まで確認した。
- [ ] 変更と無関係な既存コードを一括修正していない。
